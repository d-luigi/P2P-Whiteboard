# P2P Whiteboard brand kit

The connected-tiles mark represents two peers working on one shared board.

## Files

- `p2p-mark.svg` is the primary blue and charcoal mark.
- `p2p-mark-mono.svg` is for one-colour printing and dark UI surfaces. Set `currentColor` from CSS.
- `p2p-lockup.svg` is the horizontal wordmark lockup.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#111827` | Primary mark and text |
| Blue | `#2563EB` | Accent tile and links |
| White | `#FFFFFF` | Knockout peer dots and reversed surfaces |

Keep clear space around the mark equal to the radius of one peer dot. Do not stretch, rotate, add shadows, or recolour the two tiles independently.
